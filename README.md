# LUCompSoc Branding

## Logos

There are two versions of the logo provided:
- [bare](https://github.com/LUCompSoc/brand/tree/master/logos/bare) - This is better for smaller use cases (below 128x128)
- [normal](https://github.com/LUCompSoc/brand/tree/master/logos/normal) - This is better for larger use cases (128x128 and above)

Auto-generated favicons (from [favicon.io](https://favicon.io/favicon-converter/)) are also available in the [favicons](https://github.com/LUCompSoc/brand/tree/master/favicons) folder.
