# LUCompSoc Branding

## Favicons

Favicons for all of the logo variants (auto-generated by [favicon.io](https://favicon.io/favicon-converter/)) are also available in the [favicons](https://github.com/LUCompSoc/brand/tree/master/favicons) folder.

This includes:

* android-chrome-192x192
* android-chrome-512x512
* apple-touch-icon
* favicon.ico
* favicon-16x16
* favicon-32x32
* site.webmanifest
